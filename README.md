# Neon Afterhours — privacidade

Página pública de privacidade e suporte da WolZ Games, em português, inglês e espanhol.
Site estático, sem JavaScript, dependências, analytics ou formulários.
GitHub Pages: branch `main`, raiz `/`.

Vigência: 01/10/2026, versões de testes/pré-lançamento. Descreve a campanha local,
Google Play Games/Saved Games opcional em teste, identificação automática possível
de perfis existentes, anúncios de amostra, escolhas e exclusão por provedor.
Sem conta própria, servidor de campanhas próprio, Firebase Analytics ou compras reais.
A política não comprova funcionamento de login, sincronização ou monetização.
Reauditar antes de anúncios comerciais ou mudanças no tratamento de dados.

Fontes técnicas consultadas em 01/10/2026:
- https://developer.android.com/games/pgs/data-collection
- https://developer.android.com/games/pgs/savedgames
- https://support.google.com/googleplay/answer/9130646
- Implementação Neon `1537328`: driver direto, confirmação de cópia, conta e recuperação.

Os três documentos têm o mesmo escopo. Idiomas são escolhidos pelos links no topo;
o botão atual do jogo abre a página raiz em português. Não há redirecionamento automático.
O repositório contém somente arquivos públicos; nenhum save, imagem de conta ou segredo.
