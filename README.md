# Neon Afterhours — privacidade

Página pública da política de privacidade e contato de suporte da WolZ Games.

Site estático, sem JavaScript, dependências, analytics ou formulários.
Publicação: GitHub Pages, branch `main`, raiz `/`.

Esta política descreve a versão de testes de 30/09/2026. Reauditar antes de
ativar compras reais, autenticação, backup remoto, análise de uso ou anúncios
em produção. A publicação da política não constitui lançamento do aplicativo.

O repositório contém somente os arquivos públicos desta página, sem código,
assets licenciados, credenciais ou dados de testes do jogo.
